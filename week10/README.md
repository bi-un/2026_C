이진탐색 : 정렬된 데이터에서 원하는 값을 빠르게 찾는 방법
중간값을 구해서 타겟이 더 크면 오른쪽으로 이동(오름차순)

getchar()는 문자 하나를 입력받는 함수.
putchar()는 문자 하나를 출력하는 함수.
gets()는 문자열을 입력받는 함수.
puts()는 문자열을 출력하는 함수.
fgets()는 지정한 크기만큼 문자열을 입력받는 함수.
strlen()은 문자열 길이를 구하는 함수.
strcpy()는 문자열을 복사하는 함수.
strcmp()는 문자열을 비교하는 함수.
strcat()은 문자열을 연결하는 함수.
strtok()은 문자열을 구분자 기준으로 나누는 함수.
