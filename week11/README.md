11주차 C언어 포인터 문제

포인터와 배열, 문자열, 구조체, 이중 포인터, 동적 메모리 관리 개념 확인용 객관식 5문제입니다.

---

1. 포인터와 배열
다음 중 `int arr[3] = {10, 20, 30};` 이고 `int *p = arr;` 일 때, `arr[1]`의 값(20)을 출력하는 방법으로 틀린 것은 무엇인가요?

1) `printf("%d", arr[1]);`
2) `printf("%d", p[1]);`
3) `printf("%d", *(p + 1));`
4) `printf("%d", *p + 1);`

---

2. 포인터와 문자열
C언어에서 문자열을 포인터로 다룰 때에 대한 설명으로 가장 알맞은 것은 무엇인가요?

1) 문자열의 끝을 알리기 위해 항상 맨 뒤에 `\n`이 자동으로 들어간다.
2) `char *str = "Hello";` 처럼 선언하면 포인터 `str`은 문자열의 첫 글자 `'H'`의 주소를 가진다.
3) 포인터로 선언한 문자열은 `str[0] = 'A';` 처럼 중간 글자를 자유롭게 수정할 수 있다.
4) `char`형 포인터의 크기는 가리키는 문자열의 길이에 따라 계속 변한다.

---

3. 구조체와 포인터
구조체 포인터 변수 `p`를 사용하여 구조체 내부의 멤버 변수 `age`에 접근하려고 할 때 사용하는 연산자로 올바른 것은 무엇인가요?

1) `p.age`
2) `p->age`
3) `p&age`
4) `p::age`

---

4. 이중 포인터
다음 코드에서 `**pp`가 의미하는 값으로 올바른 것은 무엇인가요?
int a = 100;
int *p = &a;
int **pp = &p;

1) 변수 a의 주소값
2) 포인터 p의 주소값
3) 변수 a에 들어있는 값 100
4) 에러 발생 

---

5. 동적 메모리 관리
malloc 함수를 사용하여 동적으로 메모리를 할당받은 후, 프로그램이 끝나기 전에 메모리를 해제해 주기 위해 사용하는 함수는 무엇인가요?

1) delete()
2) clear()
3) free()
4) remove()
